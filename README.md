# JointForge Blender Companion

**Official Blender companion add-on for JointForge for Genesis 8, by JR Redtail.**

This free Blender add-on supports the JointForge corrective-morph workflow, including importing JCM OBJ meshes, exporting sculpted OBJ meshes, and creating mirrored JCMs. JointForge's separate commercial DAZ Studio application is **not** included in this repository.

## Compatibility

- **Blender 4.5** (the supplied add-on documentation identifies Blender 4.5.9 LTS as its confirmed target).
- Compatibility with other Blender versions is not guaranteed by this release.

## Download and install

1. Open **Releases** on this GitHub repository.
2. Download **JointForge_Blender_Companion_v1.0.0.zip** from the latest compatible release.
3. In Blender, open **Edit > Preferences > Add-ons > Install from Disk** and select the downloaded ZIP. Do not unzip the add-on ZIP for this installation step.
4. Enable the **JRD JCM OBJ Exporter** add-on.
5. In the 3D Viewport, press **N** to open the Sidebar and select the **JRD JCM** tab.

The installed add-on keeps its existing internal **JRD** names for compatibility with the established JointForge workflow. Those internal identifiers are not a separate company or an additional commercial product.

For the detailed functions, OBJ export settings, and warnings, read [`JRD_JCM_OBJ_Exporter/README.md`](JRD_JCM_OBJ_Exporter/README.md).
